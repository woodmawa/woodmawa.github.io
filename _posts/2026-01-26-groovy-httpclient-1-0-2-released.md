We're excited to announce the release of Groovy HttpClient 1.0.2! This release brings
improved virtual thread support, enhanced security features, and better test framework integration.

#### Key Updates

- Enhanced virtual thread executor for Java 21+
- Improved circuit breaker implementation
- New retry policy with exponential backoff
- Expanded test DSL capabilities

> **Update, October 2026:** 1.0.2 did not reach Maven Central; 1.0.0 is the published 1.x release.
> The current release is [2.1.0]({% post_url 2026-10-26-groovy-httpclient-2-1-0-released %}).
